# Triage Labels

The five canonical triage roles map exactly to these GitHub labels:

| Role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs information | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

Additional workflow labels used by this repo include `bug`, `enhancement`, `prd`, and the `agent-loop:*` labels synchronized by the setup scripts.
