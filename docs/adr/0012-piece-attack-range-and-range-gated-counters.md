# Piece Attack Range and Range-Gated Counters

Rune Lanes now treats attack range as a normal Hero or Unit combat stat instead of assuming every attack is adjacent. Attack legality uses hex distance only, with no blocker, line-of-sight, or straight-line restriction; counterdamage only applies when the target's own attack range reaches the attacker. This keeps Archer's range-2 Hero passive readable on the radius-3 arena while preserving reciprocal melee combat for range-1 pieces.
