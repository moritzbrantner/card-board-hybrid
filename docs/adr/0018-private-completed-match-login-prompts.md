# Private Completed Matches Use Login Prompts

Rune Lanes keeps account-owned completed Solo match summaries and replays private to the owning account, while anonymous ownerless Solo matches remain viewable by match ID and Shared match seat links remain private capabilities. When a signed-out viewer opens a private account route, the client shows a sign-in prompt with a return path instead of making completed summaries public.

This preserves match privacy without leaving direct summary or replay URLs as misleading dead ends.
