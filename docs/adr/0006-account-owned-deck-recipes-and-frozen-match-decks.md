# Account-Owned Deck Recipes And Frozen Match Decks

Rune Lanes stores player-built decks as account-owned deck recipes, not as live match piles. When a match starts, the selected recipe is frozen into concrete per-side match decks, so later edits to the account recipe cannot change an active match or replay.

Account identity is required to build and select account deck recipes, but shared-match seat links remain the authority for shared play access. Anonymous seats and default play use the system starter recipe, preserving the capability-link model while adding account-owned customization around it.
