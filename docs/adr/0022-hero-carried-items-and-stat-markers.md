# Hero-Carried Items and Stat Markers

Rune Lanes now treats carried Items as a shared Unit-or-Hero carrier model, with each Item card declaring whether it can target Units, Heroes, or both. Active Items can be priority-speed responses by spending saved carrier AP, preserving the existing action-point economy while making equipment useful during stack windows. Permanent Item stat growth is recorded as visible stat markers instead of hidden stat mutation so replay, inspection, and future removal rules can explain where carrier stats came from.
