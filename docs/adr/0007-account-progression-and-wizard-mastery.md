# Account Progression And Hero Mastery

Rune Lanes separates account progression from hero-specific mastery: completed matches award account experience for broad profile level and generic rune unlocks, while the hero used in that match earns hero mastery for its own passive skill tree. Match creation freezes the selected rune loadout and unlocked skill effects into the match snapshot, preserving replay stability and keeping later respecs or loadout changes from mutating active matches.

This keeps progression additive to the existing account and seat-link model. Anonymous play and private seat links still work, but only signed-in accounts accrue durable progression.
