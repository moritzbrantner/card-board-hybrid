# Configured Deck Recipes And Player System Loadouts

Rune Lanes treats the home-screen choice as a match loadout: a Wizard, a deck recipe or system deck recipe, and rune IDs. Account deck recipes now store their Wizard and rune configuration so they can appear as complete custom loadouts, while system deck recipes can be selected by players as well as AI opponents. Active skills are still derived from current wizard mastery and frozen at match creation, rather than being stored on deck recipes.
