# Hero Board Appearance Unlocks

Rune Lanes unlocks Hero Board appearance variants from Hero mastery and stores each signed-in player's selected appearance per Hero. The selected appearance is response-level presentation metadata: match rules, deck legality, frozen match loadouts, replay frames, and authoritative match snapshots continue to store Hero identity and match state only.

The renderer resolves the owner's selected appearance when account or seat metadata is available, then falls back to viewer-local selection or the base Hero appearance. This preserves the existing Board visual mode boundary while still letting shared-match participants show their chosen Hero appearance to other viewers.
