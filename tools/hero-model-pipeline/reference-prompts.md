# Hero Reference Prompts

These prompts produced the tracked source PNGs in `references/`. The PNGs are source inputs for TripoSR and should be reviewed before regenerating meshes.

## Shared Constraints

- Square `1024x1024`.
- Full-body character, centered.
- Front-facing or only slight 3/4 turn.
- Clean silhouette with visible head, torso, hands, and signature prop.
- Neutral white background.
- Toy-miniature / stylized tabletop-board-piece look.
- No text, UI, frame, watermark, extra characters, cropped limbs, heavy environment, dramatic perspective, or motion blur.

## Runekeeper

Use case: stylized-concept
Asset type: source reference PNG for image-to-3D hero miniature generation
Primary request: Create a clean full-body reference image of the Runekeeper hero for a fantasy tactical board game.
Subject: teal-and-gold rune caster, balanced scholar-warrior silhouette, hooded robe or light armor, visible head and torso, both hands visible, floating staff with rune details, calm stance.
Style/medium: polished stylized 3D character concept, toy-miniature / tabletop-board-piece look, readable silhouette for 3D reconstruction.
Composition/framing: square 1024x1024, full body centered, front-facing with only a very slight 3/4 turn, consistent camera height, generous padding, no cropped limbs.
Scene/backdrop: perfectly clean neutral white background, no floor plane.
Lighting/mood: even soft studio lighting with minimal shadows.
Color palette: teal, deep green-blue, warm gold accents.
Constraints: no text, no UI, no frame, no watermark, no extra characters, no heavy environment, no dramatic perspective, no motion blur.
